# Haxof · Hacking Team · AI Red Team

Base de conocimiento interna del área de **Hacking**. Reúne apuntes de investigación, herramientas, metodologías, laboratorios y referencias para consultar, reproducir y ampliar lo aprendido.

## Empezar aquí

- [Área de Hacking](areas/hacking/README.md): navegación y alcance.
- [AI Red Team](areas/hacking/ai-red-team/README.md): evaluación adversaria de sistemas de IA.
- [AI Safety](areas/hacking/ai-safety/README.md): evaluación de riesgos, comportamiento y salvaguardas de IA.
- [Cybersecurity](areas/hacking/cybersecurity/README.md): seguridad de aplicaciones, infraestructura, nube y datos.
- [Cómo contribuir](CONTRIBUTING.md): organización, nombres, estados y plantilla de investigación.

## Estructura

```text
areas/
└── hacking/
    ├── ai-red-team/
    ├── ai-safety/
    └── cybersecurity/
```

Cada sección contiene:

| Carpeta | Contenido |
| --- | --- |
| `apuntes/` | Conceptos, resúmenes y hallazgos de investigación. |
| `herramientas/` | Notas de instalación y uso, scripts y utilidades. |
| `metodologias/` | Procesos, marcos de trabajo y criterios de evaluación. |
| `laboratorios/` | Ejercicios, entornos, pruebas y resultados reproducibles. |
| `recursos/` | Papers, documentación y otras referencias comentadas. |

## Forma de trabajo

1. Elegir la sección y el tipo de contenido.
2. Crear un documento usando la [plantilla común](CONTRIBUTING.md#plantilla-comun).
3. Registrar autor, fecha, fuentes y estado.
4. Enlazar el aporte desde el índice de su carpeta.

Un apunte puede comenzar como **por explorar**, avanzar a **en pruebas** y llegar a **validado** cuando exista evidencia documentada. Validado se refiere al entorno y la versión registrados.

## Colaboración entre áreas

El contenido de Hacking se mantiene en `areas/hacking/`. Las otras áreas del equipo pueden añadirse en `areas/<nombre-del-area>/`, con su propio índice y estructura. Consulta el [índice de áreas](areas/README.md).

## Acceso

La estructura inicial se comparte públicamente para que el equipo pueda evaluarla. Se prevé volver a la visibilidad privada antes de incorporar investigaciones internas. El acceso y la ubicación definitiva en una organización se gestionan en GitHub.
