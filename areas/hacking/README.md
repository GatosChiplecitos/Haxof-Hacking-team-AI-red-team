# Hacking

Espacio de investigación y documentación del área de Hacking.

## Secciones

| Sección | Alcance |
| --- | --- |
| [AI Red Team](ai-red-team/README.md) | Evaluación adversaria de modelos, agentes y aplicaciones de IA. |
| [AI Safety](ai-safety/README.md) | Evaluación del comportamiento, riesgos y salvaguardas de IA. |
| [Cybersecurity](cybersecurity/README.md) | Seguridad de aplicaciones, infraestructura, nube, identidades y datos. |

En cada sección se organizan **apuntes**, **herramientas**, **metodologías**, **laboratorios** y **recursos**.

## Temas que se cruzan

Elegir una sección principal para el documento y enlazarlo desde las otras cuando corresponda. Por ejemplo, una investigación sobre un agente puede relacionar pruebas adversarias en AI Red Team, evaluación de sus salvaguardas en AI Safety y permisos de acceso en Cybersecurity.

## Documentar un aporte

Usar la [guía y plantilla común](../../CONTRIBUTING.md#plantilla-comun). El autor, las fuentes y el estado se registran en cada documento.
