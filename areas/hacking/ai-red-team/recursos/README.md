## Añadir un aporte

1. Crear un documento con un nombre descriptivo en esta carpeta.
2. Adaptar la [plantilla común](../../../../CONTRIBUTING.md#plantilla-comun).
3. Registrar autor, fecha, fuentes y estado.
4. Añadir el enlace y una descripción breve al índice anterior.
