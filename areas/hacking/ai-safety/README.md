# AI Safety

Investigación sobre comportamiento de sistemas de IA, evaluación de riesgos y diseño de salvaguardas.

## Explorar

| Carpeta | Contenido |
| --- | --- |
| [Apuntes](apuntes/README.md) | Conceptos, resúmenes, preguntas e ideas propias derivadas de la investigación. |
| [Herramientas](herramientas/README.md) | Documentación de herramientas, scripts y utilidades investigadas o desarrolladas. |
| [Metodologías](metodologias/README.md) | Procesos de trabajo, marcos de referencia y criterios para realizar evaluaciones. |
| [Laboratorios](laboratorios/README.md) | Ejercicios y experimentos con pasos y resultados que se puedan reproducir. |
| [Recursos](recursos/README.md) | Referencias comentadas a papers, documentación, repositorios, cursos y otros materiales. |

## Temas orientativos

- Evaluaciones de comportamiento y fiabilidad.
- Salvaguardas, supervisión humana y criterios de escalamiento.
- Riesgos, fallos y límites del sistema.
- Seguimiento de resultados y regresiones.

Los temas son una guía para clasificar futuras investigaciones; se ampliarán con los aportes.
