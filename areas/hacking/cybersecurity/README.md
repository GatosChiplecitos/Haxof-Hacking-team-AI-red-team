## Temas orientativos

- Seguridad de aplicaciones y APIs.
- Identidades, autenticación y permisos.
- Infraestructura, nube y configuraciones.
- Detección, análisis de incidentes y medidas de protección.

Los temas son una guía para clasificar futuras investigaciones; se ampliarán con los aportes.
