# Herramientas · Cybersecurity

Documentación de herramientas, scripts y utilidades investigadas o desarrolladas.

Registrar origen, versión, instalación, ejemplos de uso, resultados observados y limitaciones. Los scripts pueden acompañarse de un documento con su mismo nombre.

## Índice

Todavía no hay aportes registrados. Al añadir el primero, sustituir esta frase por una entrada en la tabla:

| Documento | Descripción | Estado |
| --- | --- | --- |

## Añadir un aporte

1. Crear un documento con un nombre descriptivo en esta carpeta.
2. Adaptar la [plantilla común](../../../../CONTRIBUTING.md#plantilla-comun).
3. Registrar autor, fecha, fuentes y estado.
4. Añadir el enlace y una descripción breve al índice anterior.
